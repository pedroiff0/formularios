# LaTeX Formulas Skill — Formulários

Instruções para edição de capítulos:

1. **Adição de Novas Fórmulas:**
   - Adicionar no capítulo correspondente em `calculos/` ou `fisicas/`.
   - Utilizar caixas destacadas ou `tcolorbox` / `empheq` quando se tratar de leis fundamentais.
2. **Teste de Compilação Rápida:**
   - Testar com `make <disciplina>-fast` antes de rodar o build completo.
